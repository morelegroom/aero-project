# Flight Assumptions

## Baseline Flight Condition

The analysis will initially consider the Cessna 152 during steady, level cruise flight.

The baseline operating condition is based on the published cruise performance data selected from the 1979 Cessna 152 Pilot's Operating Handbook.

| Parameter         |                Value | Unit |
| ----------------- | -------------------: | ---- |
| Cruise altitude   |                8,000 | ft   |
| Cruise speed      |                  107 | kt   |
| Cruise power      |                   75 | %    |
| Aircraft weight   |                 1670 | lb   |
| Flight condition  | Steady, level cruise | —    |
| Atmospheric model |                  ISA | —    |

## Flight Assumptions

The following assumptions are used to establish the baseline calculation:

### 1. Steady Flight

The aircraft is assumed to be in steady cruise, meaning that its flight condition is not changing significantly with time.

### 2. Level Flight

The aircraft is assumed to maintain constant altitude.

Under steady, level flight, the vertical forces are approximately balanced:

$$
L = W
$$

where:

* \(L\) = lift
* \(W\) = aircraft weight

### 3. Thrust and Drag

For steady cruise flight, the horizontal forces are approximately balanced:

$$
T = D
$$

where:

* \(T\) = thrust
* \(D\) = drag

The drag force will not initially be prescribed. A suitable method for establishing realistic drag data will be investigated before calculating the drag coefficient.

### 4. Atmospheric Conditions

The atmosphere is initially represented using the International Standard Atmosphere (ISA) model.

The atmospheric properties required for the baseline calculation will be determined at the selected cruise altitude of 8,000 ft.

### 5. Aircraft Weight

The published maximum takeoff weight of 1670 lb is used initially as a conservative baseline condition.

This value represents the aircraft's maximum permitted takeoff weight rather than necessarily representing its actual weight during cruise. A more representative cruise weight may be investigated in a later stage if sufficient loading and fuel data are available.

### 6. Aircraft Configuration

The aircraft is assumed to be in a normal cruise configuration, without intentional manoeuvring or unusual flight conditions.

### 7. Scope of the Baseline

The purpose of these assumptions is to establish one clearly defined reference condition.

The baseline will be used to calculate quantities such as aircraft weight, dynamic pressure, required lift and lift coefficient before investigating changes in operating conditions and aerodynamic efficiency.
