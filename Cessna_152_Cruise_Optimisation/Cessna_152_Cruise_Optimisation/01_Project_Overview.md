# Cessna 152 Cruise Performance Optimisation Study

## Objective

To develop a cruise-flight optimisation study of a Cessna 152 using published aircraft performance data and investigate the trade-off between lift generation and the associated drag penalty in order to identify an efficient operating condition.

## Background

This project extends a previous aircraft performance simulation project.

The original work demonstrated relationships between aerodynamic variables using the lift and drag equations. Following technical feedback, the methodology has been revised to place greater emphasis on real aircraft data, physical operating conditions and engineering assumptions before introducing aerodynamic coefficients.

The project will focus on the cruise phase of flight and use published Cessna 152 performance data as the basis for analysis.

## Research Question

How do changes in aircraft operating conditions affect lift generation, drag production and aerodynamic efficiency during cruise flight?
