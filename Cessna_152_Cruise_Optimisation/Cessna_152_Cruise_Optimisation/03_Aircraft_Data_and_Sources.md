# Aircraft Data and Sources

## Aircraft

The aircraft selected for this study is the **Cessna 152**.

The Cessna 152 was selected because it is a real, well-documented light aircraft with published performance data that can be used to establish a realistic baseline flight condition.

A reference copy of the **1979 Cessna 152 Pilot's Operating Handbook (POH)** is used as the primary aircraft-data source for this study.

## Source

**Cessna 152 Pilot's Operating Handbook, 1979 reference copy.**

The aircraft data used in the calculations will be taken from the same aircraft manual where possible to avoid combining specifications from different Cessna 152 model years or variants.

The published cruise condition used for the baseline calculation is:

* Cruise altitude: **8,000 ft**
* Cruise speed: **107 kt**
* Cruise power: **75%**

## Data Selection

The published 107 kt cruise speed at 8,000 ft provides a defined operating condition from which the baseline aerodynamic calculations can be developed.

The 1670 lb figure represents the aircraft's **maximum takeoff weight**. It is therefore treated as a conservative maximum-weight baseline rather than being assumed to represent the aircraft's actual weight during every cruise condition.

The aircraft data will subsequently be converted into SI units before being used in the engineering calculations.
