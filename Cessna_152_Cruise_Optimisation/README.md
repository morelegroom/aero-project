# Cessna 152 Cruise Performance Optimisation Study

This project extends the original Aircraft Performance Simulation and Parameter Sensitivity Analysis project.

The objective is to investigate aircraft cruise-flight efficiency using published Cessna 152 performance data and a structured engineering methodology.

The project was developed following technical feedback on the original model regarding the use of prescribed aerodynamic coefficients without first establishing a realistic aircraft operating condition.
