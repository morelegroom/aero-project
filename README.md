# Aircraft Performance Simulation and Parameter Sensitivity Analysis

## Project Overview

This project uses Python to simulate basic aircraft aerodynamic performance and investigate how changes in key aerodynamic parameters affect lift and drag.

The project was initially developed to calculate:

* Lift
* Drag
* Mach number
* The effect of air density on lift at different altitude conditions

The project was then extended to investigate the sensitivity of aircraft performance to changes in:

* Wing area (`S`)
* Lift coefficient (`Cl`)
* Drag coefficient (`Cd`)

The aim of the extension was to change one parameter at a time while keeping the other parameters constant, allowing the effect of each variable to be observed independently.

---

## Objectives

The project has two main objectives:

1. Develop a basic computational model of aircraft aerodynamic performance.
2. Investigate how changes in selected aerodynamic parameters affect calculated lift and drag.

This provides a simple introduction to using computational methods to explore aerodynamic relationships.

---

## Aerodynamic Theory

The simulation is based on the following equations.

### Lift

```
L = 0.5 × ρ × V² × S × Cl
```

Where:

* `L` = Lift (N)
* `ρ` = Air density (kg/m³)
* `V` = Velocity (m/s)
* `S` = Wing area (m²)
* `Cl` = Lift coefficient

### Drag

```
D = 0.5 × ρ × V² × S × Cd
```

Where:

* `D` = Drag (N)
* `ρ` = Air density (kg/m³)
* `V` = Velocity (m/s)
* `S` = Wing area (m²)
* `Cd` = Drag coefficient

### Mach Number

```
Mach = V / a
```

Where:

* `V` = Velocity (m/s)
* `a` = Speed of sound (m/s)

## Original Simulation

The original model calculates lift, drag and Mach number over a velocity range of **30–250 m/s**.

The model also compares lift at two air-density conditions:

* Sea-level air density: `ρ = 1.225 kg/m³`
* Altitude case: `ρ = 0.9 kg/m³`

This demonstrates how changes in air density affect the calculated aerodynamic forces.

## Parameter Sensitivity Analysis

The project was extended to investigate how changing individual aerodynamic parameters affects the results.

For each experiment, one parameter was changed while the remaining parameters were held constant.

### 1. Wing Area (`S`)

Three wing areas were investigated:

| Wing Area |
| --------: |
|     10 m² |
|     20 m² |
|     30 m² |

### Result

Increasing wing area increased the calculated lift at a given velocity.

This is consistent with the lift equation because lift is directly proportional to wing area:

```
L ∝ S
```

The investigation also demonstrates that wing area appears in the drag equation, meaning that changing wing area also affects calculated drag when the other parameters remain constant.

Output:

* `wing_area.png`

---

### 2. Lift Coefficient (`Cl`)

Three lift coefficient values were investigated:

| Lift Coefficient |
| ---------------: |
|              0.3 |
|              0.6 |
|              0.9 |

### Result

Increasing `Cl` increased the calculated lift at a given velocity.

This follows the relationship:

```
L ∝ Cl
```

The comparison demonstrates the effect of the lift coefficient on the aerodynamic force generated by the wing within the simplified model.

Output:

* `lift_coefficient.png`

---

### 3. Drag Coefficient (`Cd`)

Three drag coefficient values were investigated:

| Drag Coefficient |
| ---------------: |
|            0.015 |
|             0.03 |
|            0.045 |

### Result

Increasing `Cd` increased the calculated drag at a given velocity.

This follows the relationship:

```
D ∝ Cd
```

The results show that a higher drag coefficient produces a greater calculated aerodynamic drag force under the same flight conditions.

Output:

* `drag_coefficient.png`

## Summary of Investigations

| Parameter               | Values Investigated | Main Effect                                                       |
| ----------------------- | ------------------- | ----------------------------------------------------------------- |
| Wing area (`S`)         | 10, 20, 30 m²       | Increasing `S` increases calculated lift and drag                 |
| Lift coefficient (`Cl`) | 0.3, 0.6, 0.9       | Increasing `Cl` increases calculated lift                         |
| Drag coefficient (`Cd`) | 0.015, 0.03, 0.045  | Increasing `Cd` increases calculated drag                         |

## Methodology

The investigation uses a controlled-variable approach.

For each parameter:

1. A baseline value was established.
2. The selected parameter was changed to lower and higher values.
3. The remaining parameters were kept constant.
4. The aerodynamic equations were recalculated over the velocity range.
5. The results were plotted for comparison.

This approach makes it possible to identify the direct effect of each parameter without simultaneously changing multiple variables.

---

## Limitations

This is a simplified aircraft performance model intended to demonstrate fundamental aerodynamic relationships.

The model does not currently account for factors such as:

* Variation of air density continuously with altitude
* Variation of the speed of sound with atmospheric temperature
* Angle of attack
* Reynolds number
* Stall behaviour
* Induced drag
* Aircraft weight
* Thrust or engine performance
* Fuel consumption
* Detailed aircraft geometry

The results should therefore be interpreted as **simplified aerodynamic calculations rather than a complete aircraft performance model**.

## Conclusion

The extended simulation demonstrates how key aerodynamic parameters influence calculated aircraft performance.

The results are consistent with the underlying aerodynamic equations:

* Increasing wing area increases calculated lift and drag.
* Increasing lift coefficient increases calculated lift.
* Increasing drag coefficient increases calculated drag.
* Reducing air density reduces calculated lift and drag at the same velocity.

The project demonstrates the use of Python to implement aerodynamic equations, perform controlled parameter investigations and visualise engineering results.
