# Aerodynamics Project

This project simulates basic aircraft performance.

## Features
- Lift calculation
- Drag calculation
- Mach number
- Altitude comparison

## Physics
Lift = 0.5 * ρ * V² * S * Cl  
Drag = 0.5 * ρ * V² * S * Cd  
Mach = V / speed of sound  

## Output
Graphs showing aerodynamic behaviour
